SSE stream format: binary frames — 1 byte status code + 4 byte big-endian size + N bytes data. Codes: 0 = result blob, 1 = status string / special signals (rendering_folder:, final_ready:), 2 = error, 3 = queue position, 4 = queue cleared.

How to Run

Normal (production)

  • Double-click start-web-server.bat in repo root
  • Ensure LM Studio is running (Server tab, port 1234)
  • Open http://localhost:8000
  • Closing the console stops the server
Never run the server as a tracked background task inside an assistant session — it will be killed on session end. Use Start-Process or the .bat file only.

Manual start (equivalent to .bat)

  • cd server
  • ..\venv\Scripts\python.exe main.py --start-instance --host 0.0.0.0 --use-gpu

React dev frontend

  • cd front && npm run dev
  • Opens at port 5173; proxies /api/* → localhost:8000
  • Main server must be running separately

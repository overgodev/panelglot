# Contributing

This repo is maintained by @overgodev. Direct pushes to `master` are reserved
for the maintainer.

If you'd like to change the code, please open a pull request instead of
pushing directly:

1. Fork the repo (or create a branch, if you have write access).
2. Make your changes on a feature branch.
3. Open a PR against `master` describing what changed and why.
4. Wait for review/approval before merging.

PRs let changes get reviewed before they land, so please don't push straight
to `master`.
